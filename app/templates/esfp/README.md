# ESFP

Las tres plantillas proceden del archivo «NUEVO MODELO 2026.pptx». Cada una conserva dos diapositivas del diseño original: certificado y certificado de estudios.

- `CURSO`: cinco módulos.
- `DIPLOMADO` y `PROGRAMA DE ESPECIALIZACIÓN`: ocho módulos.

El backend completa los datos del participante, las fechas, el folio, las horas, los créditos, el código de estudiante y un QR nuevo. Todos los temas de módulos de un mismo certificado reciben la misma medida de letra. La altura de las filas se reparte según el largo de cada tema.

Los valores de ejemplo para «LIBRO N°» y «CALIFICACIÓN» no forman parte de la solicitud. Esos campos muestran ahora horas y créditos para evitar datos fijos incorrectos. El enlace institucional de verificación se mantiene como en el archivo de referencia.
