# Plantillas de Colegio de Profesores del Perú - Nuevo

Esta carpeta corresponde al valor de frontend:

```text
COLEGIO_DE_PROFESORES_DEL_PERU_NUEVO
```

Antes de desplegar el nuevo modelo, agrega aquí las cinco plantillas PPTX con estos
nombres exactos:

```text
plantilla_curso.pptx
plantilla_curso_de_actualizacion.pptx
plantilla_curso_de_capacitacion.pptx
plantilla_diplomado.pptx
plantilla_programa_de_especializacion.pptx
```

Las plantillas pueden usar los mismos placeholders que el modelo
`colegio_de_profesores_del_peru`.
